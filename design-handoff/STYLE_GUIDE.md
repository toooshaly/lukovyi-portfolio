## Токени робочого столу (desktop OS chrome)
| Токен | Роль |
|---|---|
| `--wall` | градієнт-шпалера (свій на кожну тему) |
| `--panel` | напівпрозора панель (blur 18–20px) |
| `--panel-strong` | щільніша панель (вікна, віджети) |
| `--panel-border` | обводка панелей |
| `--ink` / `--ink-soft` | текст / приглушений на столі |
| `--shadow` | `0 12px 40px rgba(23,37,66,.18)` |
| `--label-bg` | тло підпису іконки |

## 4 теми (набори токенів) — перемикач у віджеті
- **Blue (default):** wall `radial #6f88ae→#8ba5c6→#b3c7dd`; ink `#1c2530`
- **Sand:** wall `#c9a888→#ddc3ab→#efe0d1`; ink `#3a2c22`
- **Green:** wall `#7fa07f→#a6c0a2→#cfe0cd`; ink `#223026`
- **Dark:** wall `#2a2f38→#20242c→#14171d`; ink `#e9edf5`; panels напівпрозорі темні

## Типографіка
- **UI столу:** system-ui / -apple-system (справжній SF на Mac)
- **Контент/бренд:** General Sans (заголовки, текст) — безкоштовна
- **Моно/лейбли/цифри:** Geist Mono
- Годинник lock-екрана: дуже конденсований, легка вага

## Spacing / радіуси / тіні
- Spacing: крок 4/8px (0.5 / 1 / 1.5 / 2rem…)
- Радіуси: іконки/плитки 18px · вікна 14–16px · віджети 18px · dock 20–22px
- Тіні: м'які, кольору `rgba(23,37,66,.18–.34)`
- Glass: `backdrop-filter: blur(18–30px)` + напівпрозоре біле тло

## Принципи
- Frosted glass + м'які тіні, ніякого важкого чорного
- Один сенс на сигнал (колір/іконка = одна роль)
- Стани обов'язкові: hover / active / selected / focus
- Усе має легко лягати в код: семантичні назви, без «магічних» чисел

## Анти-патерни (не робити)
- Різкі чорні бордери, важкі drop-shadow
- Емодзі як іконки (потрібні крафтові SVG)
- Рандомні відступи/радіуси поза шкалою
- Нативне browser-виділення тексту на столі
